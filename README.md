# Группировка в виджет

Прототип для Finam X: прод-доска 8968 «Начни утро с обзора рынка» и новая операция «Сгруппировать в виджет».

Открыть: `index.html` в браузере или GitHub Pages — https://dbodaykina-ship-it.github.io/groupofwidget/

## Флоу
1. Доска открывается так же, как ссылка с прода (vx 477, vy 195, zoom 0.10).
2. Выдели всё: потяни рамкой по пустому месту доски или нажми ⌘A / Ctrl+A.
3. Нажми «Сгруппировать в виджет» рядом с «Поделиться» (или ⌘G / Ctrl+G).
4. Выделение мерцает и раскладывается по виджетам: по одному на каждый флоу — «Утренний обзор» (каскад), «Утренний обзор Роснефть», «Утренний обзор Полюс».

## Виджет
- Секция «1 Вход → 2 Рутина → 3 Результат».
- Вход: тикеры с ценой и изменением, их можно заменить, добавить или убрать.
- Рутина: статус, мини-обзоры каскада и кнопка запуска; если рутин несколько — «Запустить всё» с выбором.
- Результат: отчёт и переключение между запусками; история запусков — по часам в шапке.
- Шестерёнка: настройки выезжают из-под шапки.
- Прицел у каждого элемента — показать ноду на доске; глазик — раскрыть виджет в провода.

## Управление доской
Колесо — прокрутка, Ctrl/⌘ + колесо — зум, пробел + тянуть — двигать доску, 0 — вид с прода, 1 — вся доска.

Данные доски сняты с прода 06.10.2026; отчёты и история запусков — снимок 30.09 (последние прогоны 11.09).
